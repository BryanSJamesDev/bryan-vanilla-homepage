\## Project Objective\
\
A framework-free personal homepage built with vanilla HTML5, CSS3, and ES6\
modules: no backend, no component libraries, no jQuery, for a web\
development course assignment. The page introduces me and links out to a\
handful of my software projects through an interactive honeycomb grid, the\
site's creative/differentiating feature.\

\## Use of Generative AI\
\
I used Claude (Anthropic), specifically the model \*\*Claude Sonnet 5\*\*, via\
the Claude app, to help build this assignment. Rough breakdown of how it was\
used:\
\
\- \*\*Scaffolding\*\*: I described the assignment (vanilla HTML5/CSS3/ES6,\
&#x20; no frameworks, needs a design document, honeycomb-style creative element,\
&#x20; ESLint/Prettier config, package.json, MIT license, at least 2 real pages\
&#x20; plus a labeled AI-generated page) and asked Claude to scaffold the full\
&#x20; project structure and write the HTML/CSS/JS.\
\- \*\*Honeycomb grid CSS\*\*: asked Claude for a flexbox + \`clip-path\` technique\
&#x20; for an interlocking hexagon grid, then adjusted spacing/colors myself.\
\- \*\*JS modules\*\*: asked for small, original ES6-module functionality (theme\
&#x20; toggle, time-of-day greeting, visit counter, hex-grid captions) split into\
&#x20; separate modules and wired through \`main.js\`.\
\- \*\*\`ai-generated.html\` content\*\*: the bio blurb and "fun facts" text on that\
&#x20; page were generated by asking Claude, "Write a short, dry-humor bio blurb\
&#x20; and three fun facts about a CS grad student who does a lot of hackathons,"\
&#x20; and used with light edits. That page is explicitly labeled in-page as\
&#x20; AI-generated to satisfy the assignment's AI-generated-page requirement.\
\- \*\*Tooling/config\*\*: asked for a reasonable ESLint flat config and Prettier\
&#x20; config; ran both locally and fixed the formatting/lint issues that came up.\
\
Everything else, content accuracy about my own projects, the visual design\
direction, final wording on the real pages, and the decision to swap in the\
class's own ESLint config if one is provided, was reviewed and adjusted by\
me before submission.\
