## Project Objective

A framework-free personal homepage built with vanilla HTML5, CSS3, and ES6
modules: no backend, no component libraries, no jQuery, for a web
development course assignment. The page introduces me and links out to a
handful of my software projects through an interactive honeycomb grid, the
site's creative/differentiating feature.

## Instructions to Build / Run Locally

No build step is required, this is a static site.

1. Clone the repo:
   ```bash
   git clone https://github.com/REPLACE_ME/REPLACE_ME.git
   cd REPLACE_ME
   ```
2. Install dev dependencies (Prettier + ESLint, used only for linting/formatting):
   ```bash
   npm install
   ```
3. Open `index.html` directly in a browser, or serve it locally:
   ```bash
   npx serve .
   ```
4. Check formatting and lint before committing:
   ```bash
   npm run format
   npm run lint
   ```

## Use of Generative AI

I used Claude (Anthropic), specifically the model **Claude Sonnet 5**, via
the Claude app, to help build this assignment. Rough breakdown of how it was
used:

- **Scaffolding**: I described the assignment (vanilla HTML5/CSS3/ES6,
  no frameworks, needs a design document, honeycomb-style creative element,
  ESLint/Prettier config, package.json, MIT license, at least 2 real pages
  plus a labeled AI-generated page) and asked Claude to scaffold the full
  project structure and write the HTML/CSS/JS.
- **Honeycomb grid CSS**: asked Claude for a flexbox + `clip-path` technique
  for an interlocking hexagon grid, then adjusted spacing/colors myself.
- **JS modules**: asked for small, original ES6-module functionality (theme
  toggle, time-of-day greeting, visit counter, hex-grid captions) split into
  separate modules and wired through `main.js`.
- **`ai-generated.html` content**: the bio blurb and "fun facts" text on that
  page were generated by asking Claude, "Write a short, dry-humor bio blurb
  and three fun facts about a CS grad student who does a lot of hackathons,"
  and used with light edits. That page is explicitly labeled in-page as
  AI-generated to satisfy the assignment's AI-generated-page requirement.
- **Tooling/config**: asked for a reasonable ESLint flat config and Prettier
  config; ran both locally and fixed the formatting/lint issues that came up.

Everything else, content accuracy about my own projects, the visual design
direction, final wording on the real pages, and the decision to swap in the
class's own ESLint config if one is provided, was reviewed and adjusted by
me before submission.
